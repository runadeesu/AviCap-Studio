# AviCap Studio

Windows 向けのネイティブ動画編集ソフトです（C++20 / Win32 / Direct3D 11 / FFmpeg）。
「読み込み → タイムラインに並べる → カット・字幕・BGM・効果音 → エフェクト・色 → 書き出し」を
1 つの画面で迷わずに進められることを目標にしています。

> 状態: 0.1.0（開発版）。各機能の実装状況は [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)
> にあります。未実装・部分実装の機能もはっきり書いています。

## 特徴

- **ローカルファースト**: 動画・音声がネットに送られることはありません。クラウド AI（Claude）は
  設定で明示的に同意したときだけ使われ、送るのは「指示文」と「タイムラインの構成情報」だけです。
  利用統計の収集・送信機能は実装していません（将来用のオプトイン設定のみあり、既定でオフ）。
- **元ファイルを壊さない**: 編集はすべて非破壊です。キャッシュ・プロキシ・自動保存は元メディアと
  別のフォルダーに置かれ、クラッシュしても元メディアが削除・変更されることはありません。
- **取り消し 1000 回**、変更ごとのジャーナル保存とクラッシュ後の復元、メディアの再リンク。
- **モダンな UI**: CapCut / Premiere Pro 風の 3 ペイン構成（ライブラリ・ビューアー・インスペクター）と
  タイムライン。テーマカラー（バイオレット / シアン / ブルー / ピンク / オレンジ）を選べます。
  UI は日本語が既定（英語にも切り替え可）。
- **ライブラリ**: メディア / オーディオ（BGM・効果音・Myinstants ページを開く） / テキスト
  （タイトル・ポップテロップ・下部テロップ・ネオン・グラデーション・字幕） / エフェクト /
  トランジション（実際の効果をかけたプレビュー付き） / AI。
- **編集**: リップル・トリム・分割・リンク・スナップ・マーカー・速度（プリセット付き）・逆再生・
  キーフレーム・ブレンドモード・クロップ・比率プリセット（16:9 / 9:16 / 1:1 / 4:5 / 21:9）。
- **エフェクト**: ぼかし各種、シャープ、ブルーム、グロー、ビネット、ノイズ、フィルムグレイン、
  ピクセレート、モザイク、RGB 分離、色収差、レンズ歪み、魚眼、グリッチ、手ぶれ、色補正、
  カラーホイール、カーブ、3D LUT（.cube）、クロマキー、シェイプ / ペンマスク。
- **AI 編集（オフラインで動作）**: 無音カット、ビート検出、シーン検出、自然文での編集指示
  （指示 → プラン → プレビュー → 適用。適用は 1 回の取り消しで戻せます）。
- **字幕**: SRT / WebVTT の読み込み・書き出し（Shift_JIS / UTF-16 も自動判別）。
- **書き出し**: H.264 / HEVC / AV1 / ProRes / DNxHR。NVIDIA (NVENC) / AMD (AMF) / Intel (QSV) /
  Media Foundation のハードウェアエンコーダーを優先し、使えなければソフトウェアに自動で切り替えます。
  書き出し後に出力ファイルを検証します。

## 使い方（Windows）

1. `AviCapStudio-Setup.exe`（インストーラー）か `AviCap-Studio-Windows-Portable.zip`（ポータブル版）を使います。
2. 起動したら「メディアを読み込み」（Ctrl+I）か、ファイルをウィンドウにドラッグします。
3. メディアをタイムラインにドラッグ（ダブルクリックで再生ヘッドの位置に追加）。
4. Ctrl+K で分割、Delete で削除、Shift+Delete でリップル削除。F1 でショートカット一覧。
5. 右上の「書き出し」から保存します。

調子が悪いときは `AviCapStudio.exe --safe-mode`（ソフトウェア描画・ハードウェアデコード無効・
既定レイアウト）で起動できます。設定・キャッシュ・自動保存は `%LOCALAPPDATA%\AviCapStudio`
（ポータブル版は exe と同じフォルダーの `UserData`）にあります。

## Myinstants について

Myinstants には公開の正式 API が見当たらないため、自動取得（スクレイピング）はしていません。
アプリからは「Myinstants のページをブラウザーで開く」ことと、ユーザー自身がダウンロードした
音声ファイルを読み込む（ダウンロードフォルダーに最近保存された音声を一覧表示し、クリックで
取り込む）ことだけができます。
読み込んだ音声は元ファイルをコピーして使い、元ファイルは変更しません。利用条件は各音声の
権利者・サイトの規約に従ってください。
