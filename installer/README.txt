AviCap Studio @VERSION@

[日本語]
- AviCapStudio.exe を起動します。最初に「メディアを読み込む」から動画・音楽・画像を追加してください。
- F1 でショートカット一覧を表示できます。メニュー「ヘルプ」からログフォルダーを開けます。
- 設定・キャッシュ・自動保存は %LOCALAPPDATA%\AviCapStudio に保存されます
  （ポータブル版は AviCapStudio.exe と同じフォルダーの UserData）。
- 元のメディアファイルが変更・削除されることはありません。
- 調子が悪いときは AviCapStudio.exe --safe-mode で起動すると、ソフトウェア描画・
  ハードウェアデコード無効・既定レイアウトで起動します。

[English]
- Start AviCapStudio.exe and use "Import Media" to add video, music and images.
- Press F1 for the shortcut list; Help > Open Logs Folder for diagnostics.
- Settings, cache and autosave live in %LOCALAPPDATA%\AviCapStudio
  (portable build: the UserData folder next to AviCapStudio.exe).
- Original media files are never modified or deleted.
- If something misbehaves, start with "AviCapStudio.exe --safe-mode"
  (software rendering, no hardware decoding, default layout).
